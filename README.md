# Checkpoint

A personal inspiration hub. A Chrome extension that imports your X (Twitter) bookmarks into a calm, Pinterest-style dashboard where you can sort posts into folders, triage an unsorted inbox, and leave notes on why you saved something.

## Design skills

`.claude/skills/` holds design and motion skills used while building this project, from:

- [emilkowalski/skills](https://github.com/emilkowalski/skills)
- [jakubkrehel/skills](https://github.com/jakubkrehel/skills)
- [mengto/skills](https://github.com/mengto/skills) (UI subset: no-ai-design-slop, audit-ai-design-slop, design-first-ui-prompting, beautiful-shadows, tailwindcss)

See each repo for its license.
